# PFC Diet（私ナイズ・エディション）

既存のカロリー・食事管理アプリにある「一般的な料理名（例: カルボナーラ）で検索した大体のPFC値が本当に合っているのか分からない」という課題を解決するために作られた、**自分専用（私ナイズ）のPFCバランス管理Webアプリケーション**です。

---

## 🌟 主な特徴・機能

### 1. 📸 栄養成分表示の写真・スクショから直接取り込み
- 食品パッケージの裏面ラベルや、ECサイト・レシピ等の「栄養成分表示」を写真・スクショで取り込み。
- **Gemini API** による高精度なAI自動抽出に対応（たんぱく質 P、脂質 F、炭水化物 C、カロリー kcal を瞬時にパース）。
- APIキーがなくても、画像プレビューを見ながらテンキーで直感的に実数値を手入力可能。
- 「一般的なカルボナーラ」ではなく、「実際に食べたその商品の正確な成分」を確実に記録できます。

### 2. 🍚 主食（ご飯・パン・麺）の重量クイック計算
- 「主食は平均的なものを食べているので重量（g）でサクッと入力したい」という日常の食事スタイルに特化。
- **白米・玄米・パスタ（乾麺/茹で上がり）・食パン（6枚切り/枚数指定）・オートミール・うどん・そば** を標準搭載。
- グラム数（120g、150g、200g等）や枚数を選ぶだけで、日本食品標準成分基準に基づいたPFC・カロリーを一発算出・追加。
- 普段食べているお米やパスタの銘柄に合わせて、**100gあたりの基準値を自由にカスタマイズ**可能。

### 3. 📊 直感的なPFC残量ビジュアルダッシュボード
- 「今日あとタンパク質〇g、脂質は残り〇g、カロリーはあと〇kcal」をリアルタイムで大きく表示。
- カロリー比率（P:〇%, F:〇%, C:〇%）のバランスメーター。
- 目標PFCは手動設定のほか、**体重と目的（減量・維持・増量）からおすすめバランスを自動算出するシミュレーター**も内蔵。

### 4. ⚡ マイ食品（お気に入り）ワンタップ登録
- よく食べる食品や組み合わせを「マイ食品」に保存して、次回からは1タップで記録。

### 5. 🔒 プライバシー・オフライン安心設計
- 面倒なアカウント登録は不要。データはすべてブラウザの `LocalStorage` に保存されます。
- バックアップ（JSON形式のダウンロード / 復元）機能を標準装備。

## 🚀 使い方・ローカル開発

### 前提条件
- Node.js (v18以上推奨)
- npm

### 起動手順
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173` にアクセスしてください。

### ビルド
```bash
npm run build
```
`dist/` フォルダ配下に本番用静的ファイルが生成されます（GitHub Pages や Vercel 等にそのままデプロイ可能）。

## 🛠️ 技術スタック

- **Storage**: LocalStorage + JSON Export/Import
